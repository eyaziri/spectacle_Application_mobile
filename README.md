# 🎭 Eighty – Mobile Show Booking App

## 📌 Project Overview

The goal of this project is to develop a mobile application that allows users to **browse and book shows** based on various criteria. The app relies on the **"Gestion Spectacle"** database from the DBMS project.

## 🚀 Key Features

### 🔍 Show Browsing

#### Search for shows using multiple criteria:
- 🎭 Title  
- ⏰ Genre  
- 📍 Venue name  

#### View detailed show information including:
- 🖼️ Photos  
- 🔗 Website links  
- 🗺️ Location (Google Maps or another mapping API)  
- 🎟️ Seat availability  

### 🎫 Show Booking

- ✅ Check seat availability  
- 📝 Enter customer information to complete the booking (with login)  
- 📩 Receive confirmation and notification  

## 🛠️ Technologies Used

- 📱 **Frontend:** Java (Android Studio)  
- 💻 **Backend:** Node.js  
- 🗄️ **Database:** MySQL ("Gestion Spectacle")  
- 🗺️ **APIs:** Google Maps API
